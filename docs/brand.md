# Qingniao brand

Qingniao takes its name from the blue-green messenger bird of Chinese mythology and literature. The project connects coding agents to explicitly configured model providers.

## Voice

Useful, welcoming, and concrete. Lead with the interruption we remove from a developer's day. Explain what is available today before inviting someone to install. Prefer a small working example to a long feature checklist.

The English project name is **Qingniao**. The intended CLI command is **qing**. The current tagline is **Switch models. Keep your flow.**

## Mark

The [bird mark](assets/qingniao-mark.png) is an original AI-assisted concept created with the built-in image generation tool. Its brief is a compact blue-green messenger bird in flight, with clear geometry that remains recognizable at small sizes.

Use the supplied PNG for the README and project previews. Preserve its proportions and provide meaningful alternative text. Do not recreate it using an existing game character or commercial bird logo. A hand-refined vector master and formal name/trademark review remain pre-release work; this asset is not evidence of trademark clearance or exclusive rights.
